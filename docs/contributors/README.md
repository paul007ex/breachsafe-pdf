# Contributor documentation

These pages define maintainer checks and release evidence. They are separate from
operator-facing tutorials and references.

## Contents

1. [Release gates](release-gates.md)

## Contributor rules

- Run executable gates and record unavailable tools as `NOT RUN`.
- Keep generated PDFs and live scan artifacts out of the source repository.
- Preserve third-party licenses and first-party PolyForm metadata.
- Review documentation against the actual built binary and image.
