# Tutorials

Tutorials teach one complete path from prerequisites to a verified result. They are
not exhaustive command references.

## Contents

1. [First report](first-report.md)

## Tutorial rules

- The first path uses a checked-in fixture and does not require network access.
- Every command has an expected outcome.
- Generated artifacts stay in an external run directory.
- The tutorial links to reference and troubleshooting pages instead of duplicating
  every contract.
