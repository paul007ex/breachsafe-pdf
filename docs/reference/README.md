# Reference

These pages define the stable facts an integrator needs: commands, schemas, fields,
digests, capability statuses, and Go call boundaries.

## Reference rules

Reference pages describe executable behavior and current field names. They do not
describe planned features as if they were shipped. When a producer limitation is
known, the page names the issue and the safe current workaround.
